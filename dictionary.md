# Dictionary

## 1. Hallucination

When an AI gives an answer that is not true. It sounds confident, but the information is wrong.

## 2. Factual Accuracy

Making sure the AI gives correct information. Similar to checking if data from an API is valid.

## 3. Personalization

AI creates content that fits each user. This is like when a mobile app changes the experience based on user settings.

## 4. Localization

AI changes content for different countries or languages. It is like translating your app strings for different regions.

## 5. Intellectual Property Risk

AI might create content that belongs to someone else. This is similar to using a library with a license you do not understand.

## 6. Domain-Specific Knowledge

Special knowledge from a field. For example, AI needs medical rules for healthcare tasks. It is similar to having business logic in an app.

## 7. Controllability

How much you can guide or limit what the AI produces. It is like setting rules or parameters for a function.

## 8. Attribution

Knowing where the AI information came from. It is like tracking where your app data comes from.

## 9. Context Maintenance

AI remembers earlier parts of a conversation. This is similar to keeping state in a mobile app.

## 10. Latency Constraints

AI must answer fast enough for a good user experience. This is like keeping API calls quick so the app does not freeze.

## 11. Synthetic Data

Fake data that looks real. It is similar to using mock data when you test your app.

## 12. Distributional Mismatch

When fake data does not behave like real data. It is like testing with mock data that does not match production.

## 13. Rare Event Modeling

Trying to simulate events that almost never happen. For example, sudden crashes or strange user actions.

## 14. In Silico Prediction

Testing ideas on a computer instead of the real world. It is like using an emulator before real device testing.

## 15. Wet-Lab Validation

Testing something in the real world to see if computer predictions are correct. It is like testing your app on a real phone after using an emulator.

## 16. Prosody

The emotion, rhythm, and tone in speech. It affects how natural a voice sounds.

## 17. Voice Cloning

AI makes a voice that sounds like a specific person.

## 18. Dubbing Automation

AI creates voiceovers in other languages. It is similar to making audio versions of your content for different countries.

## 19. Boilerplate Code

Simple and repeated code that AI can create for you. It is similar to Android or iOS templates.

## 20. Function Generation

AI creates a full function from a short text description.

## 21. Creative Prototyping

Using AI to create quick design ideas. It helps explore many options fast.

## 22. Composition Control

Telling AI how to place objects in an image. It is like setting layout rules.

## 23. Photorealism

AI makes images that look like real photos.

## 24. Conversational Agent

An AI chatbot that can talk with the user and help with tasks.

## 25. Workflow Automation

AI completes several steps automatically. It is similar to using scripts to speed up your development process.
